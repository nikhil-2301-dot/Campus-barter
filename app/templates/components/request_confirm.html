{#- The sentence that explains what Decline / Cancel does on an exchange request. Used by the dialog on the request page and by the plain confirm page, so both always say the same thing. -#} {% macro confirm_text(action, req) %} {% if action == 'decline' %}

Decline {{ req['requester_name'] }}'s request for {{ req['listing_title'] }}? They will see it as declined. This cannot be undone.

{% elif req['status'] == 'accepted' %}

Cancel the accepted request for {{ req['listing_title'] }}? Contact details are hidden again and the item becomes available to other students. This cannot be undone.

{% else %}

Cancel your request for {{ req['listing_title'] }}? The owner will see it as cancelled. You can send a new request later.

{% endif %} {% endmacro %}
